# 🚀 TechSpark - Docker Based Multi-Language Online Compiler

TechSpark is a Docker-powered online compiler that securely executes Java, Python, C, and C++ programs inside isolated Docker containers.

## Features

- Java Compiler
- Python Compiler
- C Compiler
- C++ Compiler
- Docker Sandbox
- Program Input Support
- Compilation Error Handling
- Runtime Error Handling
- Automatic Temporary File Cleanup

## How to Run

### Backend

```bash
cd backend

pip install -r requirements.txt

py app.py
```

### Frontend

Open

```
frontend/index.html
```

or

```
python -m http.server
```
